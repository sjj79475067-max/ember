# 第二阶段功能自检（对标）

| 功能 | 常见开源做法 | 本系统做法 | 结论 |
|---|---|---|---|
| 每日/每周简报 | Plane 有团队邮件摘要；Vikunja 无 | 结构化统计（逾期/阻塞/变更/完成/认领/资料核验/agent 动向）+ 可选 AI 成文；无 AI 也完整可读 | 更贴合单人 + agent 场景 |
| 手机提醒 | 需自建通知服务 | Bark / ntfy / Webhook 三选一，按 P0/P1/P2 过滤，合并推送，可测速 | 持平或更好（无额外服务） |
| 定时推送 | 常需常驻 worker | 走宿主机 crontab 调一个带密钥的接口；失败不影响主流程 | 更省资源 |
| Agent 监管 | Task Master 只看项目内任务 | 跨 agent 汇总：完成数、认领数、会话数、超时认领一键释放、7 天操作流 | 更好 |
| Skill 包 | 各家格式不统一 | Claude Code Skill + Codex/AGENTS.md 指令块，同一份工作流 | 更好 |
| 已知更差 | — | 无真正的多用户协作、无移动 App | 接受（场景不需要） |
